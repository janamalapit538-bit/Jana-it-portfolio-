Ethics & Attribution

This page explains the ethical and safety practices used in this website.

Copyright & Asset Licensing

This website mainly uses original text and CSS created for this student project. No third-party images are required for the current version. The stylesheet is original project code, so there are no third-party image or font credits needed.

If third-party images, icons, or fonts are added later, their creator and license should be identified here before the website is published.

Privacy Statement

This website does not intentionally collect, store, or track personal information. It does not use analytics, tracking cookies, or advertising trackers. The contact form is included as a simple interface for the assignment and does not connect to a database or email service in this static version.

Web Safety

  • No passwords, API keys, or other secrets are included in the public code.
  • The project should be published using HTTPS.
  • Only necessary website files should be uploaded to the public repository.
  • External assets, if added, should use secure HTTPS links.

Accessibility & Inclusivity

The pages use semantic HTML, readable text, clear navigation, labels for form fields, and descriptive page titles. Since the current version does not contain content images, image alt text is not required yet. If images are added, each meaningful image should have descriptive alt text.
